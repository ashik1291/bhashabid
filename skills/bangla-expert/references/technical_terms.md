# Technical & IT Terms (তথ্যপ্রযুক্তি পরিভাষা)

## Principles
1. **Bengali word if it is in real use**: তথ্যপ্রযুক্তি, ব্যবহারকারী, নিরাপত্তা, গোপনীয়তা, হালনাগাদ, নিবন্ধন, সংরক্ষণ, সংস্করণ, তথ্য, যাচাই, কৃত্রিম বুদ্ধিমত্তা.
2. **Otherwise the established loanword, spelled by Bangla Academy rules**: স not ষ (সার্ভার, সিস্টেম, স্টোরেজ); অ্যা for /æ/ (অ্যাপ, অ্যাকাউন্ট, অ্যালগরিদম); short ি (সিকিউরিটি, ডিজিটাল); য়্য for -ware (সফটওয়্যার, হার্ডওয়্যার, ম্যালওয়্যার).
3. **Never coin obscure purisms**: not উপাত্তভাণ্ডার (database), মেঘের গণনা (cloud computing), সুতার নিরাপত্তা (thread safety), স্মৃতি ফুটো (memory leak).
4. **Formal or academic text**: on first use give the other form in parentheses, e.g. `কৃত্রিম বুদ্ধিমত্তা (এআই)`, `যাচাইকরণ (অথেনটিকেশন)`; then stay consistent.
5. **Keep in original English**: code, commands, file names, APIs, error messages, product and brand names (`git push`, `npm install`, `config.json`, `404 Not Found`, Python, GitHub, Windows).
6. **Bengali grammar around loanwords**: loan noun + Bengali verb (`ফাইলটি আপলোড করুন`, `অ্যাপ ইনস্টল করুন`); Bengali plural and case (`সার্ভারগুলো`, `ডেটাবেসে`); never English inflection (✗ ফাইলস, আপলোডেড, ডাউনলোডিং করা).
7. **Standard forms**: ডেটা / ডেটাবেস (not ডাটা), মেশিন লার্নিং (not যন্ত্র শিখন); keep one form throughout a document.

✗ `ইউজাররা ফাইলস আপলোড করার পরে সিস্টেম সেগুলো প্রসেসিং করে।`
✓ `ব্যবহারকারীরা ফাইল আপলোড করার পর সিস্টেম সেগুলো প্রক্রিয়া করে।`

| Software engineering | code → কোড · programming / programmer / developer → প্রোগ্রামিং / প্রোগ্রামার / ডেভেলপার · algorithm → অ্যালগরিদম · bug / debugging → বাগ / ডিবাগিং · version / release → সংস্করণ / রিলিজ · deploy → ডিপ্লয় করা / চালু করা · interface / API → ইন্টারফেস / এপিআই · frontend / backend → ফ্রন্টএন্ড / ব্যাকএন্ড · cache → ক্যাশ · memory leak → মেমোরি লিক · thread safety → থ্রেড সেফটি · open source → ওপেন সোর্স · processing → প্রক্রিয়াকরণ |
